# SFIA test fixture

Small **Sprint 1 slice** of real SFIA 9 structure for contract tests.

- Categories: Strategy and architecture, Development and implementation
- Subcategories: Strategy and planning, Systems development
- Skills (with their real SFIA 9 level sets): `ITSP` Strategic planning (4–7),
  `ISCO` Information systems coordination (6–7), `IRMG` Information management
  (3–7), `PROG` Programming/software development (2–6), `TEST` Functional
  testing (1–6) — 22 skill-level pairs in all
- Same document shape as the full structure file written by
  `python -m ta_taxonomies.suites.sfia.fetch` (under gitignored `data/sfia/`)

**Structure only.** Codes, names, slugs and level numbers — no skill
descriptions, level descriptions or guidance notes. SFIA's descriptive text
is licensed and is never committed; the loader adds `sfia_ref` citations and
`url` pointers to sfia-online.org instead.

`ISCO` here is SFIA's *Information systems coordination* skill, unrelated to
the ISCO occupation classification ESCO uses — kept on purpose as the
code-collision case.
